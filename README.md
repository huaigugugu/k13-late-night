# K-13 深夜放送

一个**模拟恐怖（analog horror）**互动页面：1987 年 11 月 3 日凌晨三点，你在一台老电视前换台。

不是滚动网页，是**一台电视**——按遥控器上的频道键换台，全屏 4:3 画面，VHS 雪花、扫描线、时间码、磁迹错位。

零图片、零音频文件、零依赖：所有画面是 CSS + SVG 画的，所有声音是 Web Audio 实时合成的。

---

## 打开

双击 `index.html`。建议 Chrome / Edge / Safari。

部署：把 `index.html`、`README.md`、`.nojekyll` 传到仓库根目录，Settings → Pages → Branch `main` / root。

---

## 怎么玩

1. 先按 **POWER**（不开机什么都看不到，这是故意的）
2. 用遥控器或键盘换台：

   | 频道 | 节目 |
   |---|---|
   | **02** | 农事气象 |
   | **04** | 小熊给你讲故事 |
   | **07** | 家庭录像（自录） |
   | **09** | 深夜布道 |
   | **13** | ——— 该频道不存在 ——— |
   | **AUX** | 维护通道 |

3. 键盘：`←/→` 切台、数字键直选、`P` 开关机、`G` 节目单、`Esc` 关节目单

### 会发生的几件事

- **07 台**：蛋糕上的蜡烛在烧。待几秒，门口会多一个人，字幕从「爸爸 · 妈妈 · 我」变成「……还有谁？」
- **04 台**：小熊问「现在有几个小朋友在看？」，八秒后自己回答「……数到了。是 1 个。」
- **13 台**：纯雪花。待三秒会浮出一个轮廓。**再回来一次**就会出事。
- **AUX**：检测到「外部输入」，然后告诉你「该输入不属于本台」。
- **坐着不动 46 秒**，电视会自己换台。
- 换台太多次（或第二次进 13 台）→ **紧急广播**接管画面：红顶栏、ON AIR、双音警报，播报你的系统类型、本地时间，以及——
- 广播结束电视关机，只剩一行字。再按一次 **POWER**，画面变成一台电视里的电视里的电视。

## 第几次收看

这个站点记不住你，但**链接记得**。

- 地址里没有 `?v=`，就是第 1 次。
- 开机的一瞬间，页面会把地址栏悄悄改成 `?v=下一次`，用的是 `history.replaceState`，不刷新、不跳转。
- 所以：**你把链接复制发给别人，对方打开时看到的数字，正好比你大 1。**

它出现在三个地方：AUX 维护通道的「本台已被收看 N 次」、紧急广播的「观看者 1 名 · 第 N 次收看」、结尾的「这是第 N 次」。

想手动跳到某一个数字，直接改地址：`index.html?v=41`。

## ⚠️ 提示

- 有**突然的全屏画面切换 + 警报音**（不是突脸，但也不温柔）。声音需要按一次 POWER 才会出现——浏览器不允许页面自己出声。
- 系统开启「减少动态效果」后：换台不再跳帧、滚动亮带停用、关机不塌缩成点。
- 想重来：刷新页面（不过你注意，刷新一次数字也会 +1）。

## 结构

单文件 `index.html`：

| 部分 | 说明 |
|---|---|
| `.screen` | 4:3 视口，内含 `#stage`（各频道画面）、`#snow`（canvas 雪花）、`#osd`（台标/时间码）、`#ease`（紧急广播）、`#ghost13` |
| `.crt*` / `.roll` / `.track` | 扫描线、暗角、玻璃反光、滚动亮带、磁迹错位条 |
| 声音 | `audioInit()` 建一条总线：磁带嘶声（白噪声 → 高通 → 低通）+ 50/100Hz 电源嗡鸣；换台是带通噪声脉冲；紧急广播是 853/960Hz 双音 |
| 频道 | `#stage[data-ch="07"] .ch-07` 这组选择器控制显隐，`tune()` 只改 `data-ch` |
| 机关 | `afterTune()` 里按频道挂 setTimeout；`startEAS()` 是「这不是测试」的整段流程；`viewNo` / `bumpViewURL()` 是第几次收看 |
